about=QGIS Ribbon replaces the QGIS toolbars with a ribbon. Commands are sorted into tabs and groups (Map, Insert, Analysis, View, Edit, Imagery, Share, Extensions). Contextual tabs appear for the active vector layer, table or raster. It includes a Quick Access Toolbar, KeyTips for keyboard use (Alt), a command search, a graphical editor to customize tabs, groups and galleries, saved and shareable arrangements, light and dark appearance, and a tab for the commands of installed plugins. The ribbon only calls existing QGIS functions; the panels stay unchanged, the menu bar can optionally be hidden, and deactivating the plugin restores the QGIS toolbars exactly. User interface in English and German, with a built-in guide (Help > Plugins > QGIS Ribbon Guide). The layout follows the ribbon concept of ArcGIS Pro to help users switching to QGIS. This is an independent project, not affiliated with or endorsed by Esri, and it contains no Esri icons, texts or graphics. Tested on Windows with QGIS 3.44. No extra Python packages needed (uses PyYAML, which ships with QGIS).
